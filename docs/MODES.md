# Режимы и цели

Режим и цель задаются директивами в начале главного файла. Это не флаги командной строки.

| Директива | Что получается | Запуск |
|---|---|---|
| `$hight` | обычная программа (Linux x86-64 ELF) | `./prog` |
| `$mid` | обычная программа | `./prog` |
| `$low` | обычная программа | `./prog` |
| `$mid` / `$low` + `$kernel` | ядро: ELF64 без среды выполнения | нужен загрузчик |
| `$low` + `$boot` | загрузчик: образ диска для BIOS | QEMU / BIOS |

`$hight` вместе с `$kernel` или `$boot` — ошибка. `$boot` требует `$low`.
Главный файл обязан иметь директиву режима. Импортируемые файлы могут её не иметь;
если имеют, она должна совпасть с режимом программы. `$kernel`/`$boot` допустимы только в главном файле.

## Что разрешено

| Возможность | `$hight` | `$mid` | `$low` | `$kernel` | `$boot` |
|---|---|---|---|---|---|
| обычные типы, структуры, `make`, `a[i]`, `deref`, `addr` | да | да | да | да (кроме `make`/`alloc`) | то же |
| `cast` указатель ↔ число, арифметика указателей | нет* | да | да | да | да |
| `asm("hex")` | нет | нет | да | только `$low` | да |
| `syscall`, `argc`, `argv`, `alloc`, `make` | да | да | да | нет | нет |
| инструкции железа (`inb`, `outb`, `cli`, `lidt`, ...) | нет | нет | нет | да | да |
| `@interrupt`, `@exception` | нет | нет | нет | да | да |
| `print`, `puti`, `exit` | syscall | syscall | syscall | VGA | VGA |

\* Встроенная стандартная библиотека (`std.*`) доверенная и может использовать небезопасные операции в любом режиме.
