# Известные ограничения (0.4.1)

Честный список того, чего пока нет или что не доказано проверкой.

## Платформы и форматы
- Генератор кода только один: **x86-64**. Форматы: ELF64 для Linux (`ET_EXEC`, один сегмент RWX),
  ELF64 «ядро» (старшая половина адресов) и сырой образ диска для BIOS (`$boot`).
- Поддерживаемые ОС для обычных программ: **Linux x86-64** (используются системные вызовы напрямую).
  Windows, macOS, ARM64, UEFI не поддерживаются, совместимость не заявляется.
- ELF не динамический: нет libc, нет подключения внешних функций и объектных файлов, нет отладочных символов.

## Язык
- Константные выражения считаются как знаковые `i64`: `>>` в них арифметический, даже если результат
  потом пойдёт в `u64`. Для логического сдвига старшего бита используй переменную типа `u64`.
- Нет: строкового типа (строка — это `ptr` на «длина + байты»), срезов, перечислений, объединений,
  псевдонимов типов, дженериков, структур по значению (только через `ptr<T>`), типизированных констант.
- Нет проверки границ массивов и срезов: `a[i]` и `deref(p)` не проверяются ни в одном режиме.
- Нет автоматического освобождения памяти: `make`/`alloc` выделяют страницы через `mmap` без `free`.
- Нет оптимизатора: код — простой стековый, `-O0`. Бенчмарков и сравнений с C/Rust нет.
- Ошибки типов указывают на начало оператора, а не на точное подвыражение.

## Инструменты
- Команды: `build`, `run`, `check`, `inst`, `list`, `rm`, `path`, `keys`, `version`. Нет `format`, `test` (для Nq-кода),
  `clean`, линтера, отладочной информации, профилирования.
- `nqc inst`: нет lock-файла, контрольных сумм и точных версий; зависимости берутся из ветки/тега по умолчанию.
- Внутреннего промежуточного представления нет: генератор x86-64 работает прямо по AST.

## Загрузчик и ядро
- Встроенные `print`/`puti` в `$kernel`/`$boot` пишут прямо в VGA без переноса строки, прокрутки и контроля
  границ экрана: для нормального вывода используй `std.vga`.
- Для `$boot` есть тесты в QEMU (`tests/qemu`, `TestQEMU*`), но их прогон ещё не подтверждён; на реальном железе загрузчик не проверялся.
- Загрузчик читает до 900 секторов через int 13h (расширенное чтение); нет обработки ошибок диска кроме остановки.
- Таблицы страниц отображают 1 ГиБ 1:1; для большего объёма ядро должно построить свои.
- `$kernel` — ELF64 без собственного загрузчика: ему нужен внешний загрузчик (нет заголовка Multiboot/Limine).
- Нет SMP, ACPI, APIC (используется 8259 PIC), USB, дисковых драйверов.

## Статус проверки
Версия 0.4.0 не собиралась. 0.4.1 исправляет известные ошибки сборки; полный прогон `go test` на CI —
обязательное условие выпуска. Если сборка падает, пришлите вывод `go build` — это приоритетная ошибка.
